Identity architecture: two different access questions

Who is the principal? Then may that principal perform this action on this resource? Authentication and federation supply trusted identity; authorization evaluates the requested access.

Keep these identities separate

The user may be allowed to read one manual while the backend role can query an entire index. The application must carry user scope into retrieval and tool authorization. A signed-in user does not inherit every permission of the backend role.
