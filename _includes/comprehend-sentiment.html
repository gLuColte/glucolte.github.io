Comprehend: DetectSentiment vs DetectTargetedSentiment

Both are built-in, pre-trained APIs: no labeled training data, LLM prompt, or model hosting to maintain.

  • DetectSentiment: one overall label for the whole text — POSITIVE, NEGATIVE, NEUTRAL, or MIXED — plus scores for all four.
  • DetectTargetedSentiment: sentiment for each detected entity mention, such as a product or feature, with scores and grouped mentions. It does not return one whole-review label.

Review: “Great battery, terrible screen.” Illustrative results:

DetectSentiment
  Whole review → MIXED

DetectTargetedSentiment
  Battery → POSITIVE
  Screen  → NEGATIVE
Exam Clue

One label per review in DynamoDB + no prompt + no training data → DetectSentiment. Feedback about individual products/features → DetectTargetedSentiment.

Remember: Sentiment = whole text; Targeted = specific entities. More granular output is useful only when the task needs it.
