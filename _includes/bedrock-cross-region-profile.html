Cross-Region inference profile — routing and IAM

An inference profile is a Bedrock resource identifying a model and its routing destinations. For a cross-Region call, pass the profile ID/ARN as modelId; Bedrock chooses a destination Region to run inference.

Example routing:
Lambda in Region A
  ↓ local Bedrock endpoint
Cross-Region profile
  ↓ route to ONE destination
  ├─ Model in Region A
  ├─ Model in Region B
  └─ Model in Region C
  ↓ response to Lambda

Lambda stays in its source Region; model processing can cross Regions. A US geographic profile stays within its listed US Regions, not necessarily the caller's Region. This spreads inference capacity; it does not move or fail over the application.

Exam Rule: one model, only through this profile
  1. Allow bedrock:InvokeModel on the profile ARN.
  2. Allow it on this model's ARNs in the source and every destination Region, with bedrock:InferenceProfileArn equal to that profile ARN on the model statement.

Remember: profile + all model Regions + profile condition. Source-only permissions miss destinations; omitting the condition permits direct calls. Replace the old wildcard Allow so it cannot bypass this restriction.

Use the chosen profile's actual Region list; IAM/SCPs must permit its route. AWS geographic routing and permissions.
