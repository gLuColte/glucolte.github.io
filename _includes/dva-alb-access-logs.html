Who called /GetOrder, and where did the time go?

Client → ALB → private target → response. An access log records request-level evidence, including some requests that never reach a target. Logging must be enabled; delivery is best effort.

Timing caveat. These fields describe different boundaries, not a full browser stopwatch. Upload/WAF behavior affects attribution; -1 can mean a processing phase could not complete. A trace ID helps correlate evidence but does not create downstream spans.

Delivery. Traditional access logging writes compressed files to S3 (disabled by default). Use a same-Region bucket and the required log-delivery bucket policy. AWS also supports the newer CloudWatch Logs integration, with destinations including CloudWatch Logs, Firehose and S3. Choose the delivery path deliberately; CloudWatch metrics are a separate signal.
